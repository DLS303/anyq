# Анык — «Согласование материалов» (сторона снабжения)
Автор: Снабжение, 19.10.2026. Для ТЗ `anyq_procore_tz_IT.md`, п. 3. Функция по умолчанию выключена, включается в настройках. Тесты только на выдуманных данных.

## Зачем
Заказчик, проектировщик или технадзор заранее одобряет материал: марку, производителя, характеристики и допустимые аналоги. Снабжение заказывает только одобренное, и поэтому не бывает переделок и споров при приёмке. Одобренный материал сразу попадает в заявку в 3 шага и в сравнение цен.

## Сценарий (≤3 нажатия на каждую роль)
1. **Прораб или снабженец**: «Новое согласование», затем выбрать позицию из сметы или заявки (или ввести вручную), приложить фото, паспорт или сертификат и нажать «Отправить».
2. **Согласующий** (заказчик, проектировщик или технадзор): открыть уведомление и выбрать «Одобрить», «Одобрить с замечанием» или «Отклонить», указав причину.
3. **Снабженец**: на одобренной карточке нажать кнопку «В заявку», и позиция уходит в заявку уже с характеристиками и списком разрешённых аналогов.

## Поля карточки
| Поле | Тип | Обяз. | Примечание |

| Наименование | текст | да | например «Сэндвич-панель стеновая» |
| Марка / артикул / ГОСТ/СТ РК | текст | да | |
| Производитель | текст | нет | |

| Ед. изм. / кол-во | справочник / число | да | |

## Статусы
`Черновик`, затем `На согласовании`, затем один из трёх: `Одобрено`, `Одобрено с замечанием` или `Отклонено`. Отклонённое можно отправить снова как новую версию. Отдельно бывает `Отозвано`.
Статус `Одобрено` действует только для указанного объекта. Если меняется марка, нужна новая версия.

## Связка со снабжением (главное)
1. **Заявка в 3 шага.** Позиция с пометкой «требует согласования» не отправляется поставщикам, пока материал не получит статус `Одобрено`. Показываем жёлтую плашку «Не согласовано» и кнопку «Отправить на согласование».
2. **Сравнение цен.** В сравнении сравниваем только одобренную марку и её допустимые аналоги. Если поставщик предлагает другую марку, рядом с ценой появляется значок «не согласовано» и кнопка «Согласовать замену», которая создаёт новое согласование с уже заполненными полями.
3. **Бюджет объекта.** Если ориентировочная цена превышает план бюджета по статье, согласующий видит предупреждение. Расчёт он не блокирует.
4. **Повтор заказа.** При повторе заказа на том же объекте одобренный материал подтягивается без повторного согласования.
5. **Приёмка на объекте.** При приёмке поставки прораб сверяет марку с одобренной карточкой. Если марка не совпадает, он ставит отметку «Несоответствие», которая создаёт замечание с фото (п. 2 плана).
6. **Документы для ЭСФ/СНТ.** Сертификаты из согласования прикрепляются к поставке, чтобы при проверке их не искать.

## Модель данных (кратко)
- `material_approval` (id, object_id, request_item_id?, name, brand, manufacturer, unit, qty, need_by, status, version, parent_id?, created_by, created_at)
- `material_approval_spec` (approval_id, param, value)
- `material_approval_file` (approval_id, file_id, kind: cert|passport|declaration|photo)
- `material_approval_analog` (approval_id, brand, manufacturer)
- `material_approval_step` (approval_id, approver_id, order, decision, comment, decided_at)
- связь `request_item.approval_id` (nullable) + флаг `request_item.requires_approval`

## Критерии приёмки
- Если функция выключена, в интерфейсе нет ни следа, а заявка работает как в пилоте.
- Создать и отправить согласование можно за ≤3 нажатия, решение согласующего — за ≤2.
- Позицию с флагом «требует согласования» нельзя отправить поставщикам до статуса `Одобрено` (проверяем тестом).
- Цена поставщика за неодобренную марку помечена в сравнении.
- Кнопка «В заявку» на одобренной карточке создаёт позицию с маркой, характеристиками и аналогами.
- Отклонение без причины невозможно, история версий сохраняется.
- Уведомления согласующему и автору при каждом изменении статуса, напоминание за 1 день до даты «нужно к» (срок «нужно к» — это дата из карточки).
- Все тесты используют только выдуманные данные. Цены без источника не выводятся.

## Чего не делаем в v1.0
Проверку сертификатов по внешним реестрам и автоматическое распознавание документов (ИИ) включаем позже, после выбора поставщика ИИ.
