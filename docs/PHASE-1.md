# Фаза 1 — витрина участков и цифровой паспорт

Источник: ТЗ SuperAPP 15.09.2026, §8. Релиз: 15.01.2027.

## В этом скелете

- Публичный веб-портал (Next.js)
- Каталог участков: список + карта OSM, фильтры
- Цифровой паспорт v1 (ручной ввод)
- Кабинет продавца, очередь модератора
- Бейдж «Проверено» только после кадастра + модерации
- RU / KK
- API-шлюз с модулями будущих микросервисов

## Не входит (фазы 2–4)

Эскроу, Kaspi Pay, eGov QR, Flutter, KENML, Pin-on-Plan, e-Qurylys, E-License, Elasticsearch, Kafka, S3.

Гос-API: graceful degradation — ручной ввод и модерация, коннекторы появятся позже.

## Данные сейчас

Файл `data/db.json` (Docker на машине нет). Целевой контур: `docker compose up -d` → PostgreSQL + PostGIS.

В контуре фазы 1 также: мастер публикации с контуром, паспорт v1, Trust Score, калькулятор освоения, избранное, заявка на просмотр, фото, сравнение до 3 участков, радиус от точки на карте, автоподсказки, сохранённые поиски, цикл «доработка → правка → снова на модерацию».
