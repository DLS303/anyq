# Фаза 2 — специалисты, CRM, мессенджер

Источник: ТЗ SuperAPP §8. Релиз: 01.05.2027.

## В контуре

- Каталог специалистов (изыскания, юраудит, архитектура, СМР, технадзор, техника)
- Карточка: БИН/ИИН, лицензия I/II/III (заглушка E-License), прайс, портфолио на реальных участках
- Заказ услуги → чат + сделка в CRM
- Рейтинг и отзыв только после статуса `completed`
- Канбан трёх воронок: продажа участка / проектирование / подряд
- P2P-чат

## Не входит (фазы 3–4)

Эскроу, Kaspi Pay, eGov QR, Flutter, KENML, Pin-on-Plan, e-Qurylys.
