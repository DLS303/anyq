# Анык — оболочка Android и iOS

Один веб-код (`apps/web`) открывается внутри нативной оболочки Capacitor (`apps/capacitor`). Отдельного мобильного интерфейса нет.

Каталог `apps/mobile` — старое приложение на Flutter. Оно заморожено: его не собирают, не подключают к этой оболочке и не меняют в этом репозитории.

Идентификатор приложения: `kz.dls.anyq`. Имя на экране устройства: **Анык**.

## Что нужно для сборки

- Node.js 22
- JDK 21
- Android SDK 36 и build-tools 36 (переменная `ANDROID_HOME`)
- Для сборки iOS — macOS с Xcode 15+ и CocoaPods. На Linux собирается только Android

Платные аккаунты магазинов для локальной и CI-сборки не нужны. Подпись релиза включается только когда в GitHub Actions уже лежат секреты.

## Адрес сервера

Оболочка не хранит копию сайта. При `npm run sync` адрес записывается в нативный проект из переменной `ANYQ_APP_URL`.

Домен продакшена ещё не куплен. Если переменную не задать, подставляется заглушка:

```text
https://app.anyq.example
```

Это не живой сайт. Имя `.example` зарезервировано и никуда не ведёт. Пока домен не куплен, приложение покажет экран «Нет интернета» / «Интернет жоқ» и кнопку повтора.

Локальная и тестовая сборка:

```bash
# эмулятор Android видит компьютер как 10.0.2.2
ANYQ_APP_URL=http://10.0.2.2:3000 npm run sync:android

# телефон в той же сети
ANYQ_APP_URL=http://192.168.1.20:3000 npm run sync

# стенд
ANYQ_APP_URL=https://staging.example.com npm run sync
```

Адрес `http://` включает cleartext только в этой сборке. Для камеры и голосовой заметки надёжнее HTTPS: часть WebView не даёт микрофон на обычном HTTP. Веб-сервер для проверки с телефона или эмулятора нужно слушать на `0.0.0.0`, не только на `127.0.0.1`.

После смены адреса команду sync нужно выполнить заново и пересобрать приложение. Уже установленный APK старый адрес сам не подхватит.

## Сборка

```bash
cd apps/capacitor
npm ci
npm run android:debug
npm run android:aab
```

- Отладочный APK: `android/app/build/outputs/apk/debug/app-debug.apk`. Его подписывает отладочный ключ Android, его можно поставить на устройство или эмулятор.
- Release AAB: `android/app/build/outputs/bundle/release/app-release.aab`. Без секретов подписи архив не подписывается. В Google Play его загрузить нельзя, пока не появится keystore.

iOS на Mac:

```bash
cd apps/capacitor
npm ci
npm run sync:ios
cd ios/App
xcodebuild \
  -project App.xcodeproj \
  -scheme App \
  -configuration Debug \
  -sdk iphonesimulator \
  -destination 'generic/platform=iOS Simulator' \
  CODE_SIGNING_ALLOWED=NO \
  CODE_SIGNING_REQUIRED=NO \
  build
```

Так получается сборка симулятора без подписи. Для App Store нужны сертификат и профиль.

## Что делает оболочка

В обычном браузере поведение сайта не меняется. Нативные вызовы включаются только если страница видит мост Capacitor.

- Камера: снимок для ежедневного отчёта и фото дефекта. Если камера недоступна или плагин не ответил, остаётся обычный выбор файла.
- Микрофон: перед голосовой заметкой запрашивается разрешение. Запись по-прежнему идёт через `getUserMedia`.
- Геолокация только на переднем плане и только когда страница сама вызывает `navigator.geolocation`. Фоновое слежение не запрашивается.
- Поделиться: ссылка WhatsApp (`wa.me`) открывает системное меню «Поделиться», где есть WhatsApp.
- Внешние ссылки открываются в системном браузере, не внутри WebView.
- Скачивание xlsx, PDF и CSV в оболочке кладёт файл в «Загрузки» на Android и в «Файлы» плюс меню «Поделиться» на iOS.
- Экран без сети: «Нет интернета» и «Повторить», на казахском «Интернет жоқ» и «Қайталау». Язык берётся из адреса `/ru` или `/kk`, а на локальной странице ошибки — из языка устройства.
- Кнопка «Назад» на Android возвращает по истории, а с первого экрана сворачивает приложение.
- Сплэш и статус-бар цвета марки `#2F5B8A` / `#EFE8DE`.

Тексты разрешений на русском лежат в `android/app/src/main/AndroidManifest.xml` и в `ios/App/App/Info.plist` (камера, микрофон, фотоплёнка, геолокация при использовании).

## Иконка

Исходник — `apps/capacitor/assets/logo.png`: буквы «Ан» на прозрачном фоне. Фон иконки и сплэша — `#2F5B8A`. Чтобы заменить знак, положите новый `assets/logo.png` (или поправьте текст в `scripts/render_icon.py`) и выполните:

```bash
cd apps/capacitor
npm run assets
```

Нужны уже созданные каталоги `android` и `ios`.

## Установка с сайта (PWA)

У веба есть `manifest.webmanifest` и service worker. Worker хранит только статику (`/_next/static`, иконки, манифест, favicon). Запросы `/v1/`, `/uploads/`, `/health`, `/api/` и ответы с заголовком Authorization не кэшируются. Внутри оболочки Capacitor worker не регистрируется.

## GitHub Actions

Файл `.github/workflows/mobile.yml`:

- вручную (`workflow_dispatch`), можно передать `app_url`;
- на pull request, если изменились оболочка, мост веба, манифест, service worker или эта инструкция.

Ubuntu собирает debug APK и неподписанный release AAB. macOS собирает приложение симулятора без подписи. Оба результата попадают в артефакты.

Существующий `.github/workflows/ci.yml` этот поток не заменяет и не меняется.

Подпись пропускается, пока нет секретов:

| Секрет | Зачем |
| --- | --- |
| `ANDROID_KEYSTORE_BASE64` | keystore в base64 |
| `ANDROID_KEYSTORE_PASSWORD` | пароль хранилища |
| `ANDROID_KEY_ALIAS` | алиас ключа |
| `ANDROID_KEY_PASSWORD` | пароль ключа |
| `APPLE_CERTIFICATE_BASE64` | сертификат распространения |
| `APPLE_CERTIFICATE_PASSWORD` | пароль сертификата |
| `APPLE_TEAM_ID` | команда Apple |

Когда секреты появятся, шаг Android раскодирует keystore, а Gradle подпишет release. Шаг Apple пока только фиксирует, что секреты есть: сборка симулятора остаётся без подписи. Магазинную подпись iOS добавляют отдельно, на Mac или на macOS-раннере.

## Что нужно купить, чтобы опубликовать

Сборка из этого репозитория денег не требует. Публикация требует аккаунтов магазинов:

- **Google Play Console** — разовый регистрационный взнос (сейчас 25 USD). Дальше можно обновлять приложение без годовой платы за аккаунт.
- **Apple Developer Program** — годовая плата (сейчас 99 USD). Без неё нет сертификата, TestFlight и App Store.
- **Mac или macOS в CI** — чтобы подписать iOS и отправить сборку. Симуляторную сборку из этого workflow в App Store загрузить нельзя.
- **Домен и HTTPS** — в магазин нужен постоянный адрес сервера вместо `https://app.anyq.example`.
- **URL политики конфиденциальности** — публичная страница. В приложении она уже есть: `/ru/legal/privacy`. В карточке магазина указывают полный адрес, например `https://<домен>/ru/legal/privacy`, после того как домен куплен и сайт открыт снаружи.
- **Тексты карточки и скриншоты** — название, краткое и полное описание, иконка 512×512 (Google) и 1024×1024 (Apple), скриншоты телефона. Для проверки удобно снять вход, список объектов, закупку и ежедневный отчёт с камерой.

Черновик описания, его нужно вычитать перед отправкой:

> Анык — рабочее приложение для объекта: заявки на материалы, цены рядом, повтор заказа, бюджет, ежедневный отчёт с фото и голосовой заметкой. Русский и казахский.

## Проверка App Store, пункт 4.2

Apple отклоняет приложения, которые только показывают сайт и не дают ничего сверх браузера (Guideline 4.2, Minimum Functionality). Оболочка с одним WebView попадает в эту зону риска, даже если сайт полезный.

Что в этой сборке отвечает на замечание ревьюера:

- камера снимает фото отчёта и дефекта, а не только открывает `<input type="file">`;
- микрофон запрашивается для голосовой заметки;
- геолокация — системное разрешение «при использовании», без фона;
- ссылка в WhatsApp уходит в системное меню «Поделиться»;
- чужие сайты открываются в системном браузере;
- xlsx и PDF сохраняются в файлы устройства;
- без сети есть свой экран и повтор, а не стандартная ошибка браузера;
- есть сплэш, иконка, статус-бар и кнопка «Назад».

Это не гарантия одобрения. В заметке для ревьюера стоит написать, под какой учётной записью смотреть объект, и прямо указать ежедневный отчёт, фото, голос и выгрузку конкурентного листа. Если ревьюер сочтёт функции слишком тонкими, придётся либо углубить нативную часть, либо не подавать iOS, пока сценарии не станут очевидны на видео.

Google Play тоже смотрит на обёртки, но основной письменный риск именно у Apple 4.2.
