# ANYQ Mobile (АНЫҚ) — Мобильное приложение

Кроссплатформенное мобильное приложение на **Flutter (Dart)** для экосистемы земли, стройки и архитектуры РК.

Полностью воспроизводит функционал и дизайн-систему веб-платформы ANYQ («ясное стекло над землёй»).

## 🌟 Реализованные разделы

### 1. Витрина участков (Каталог и Карта)
- Быстрый поиск с автофильтрацией по районам (Медеуский, Талгарский, Наурызбайский, Бостандыкский).
- Фильтры: *Только с паспортом*, *Только с газом*, *Только со светом*.
- Переключение режимов: **Интерактивная карта** и **Список карточек**.
- Векторная карта Алматы с силуэтом гор Заилийского Алатау, дорогами и контурами участков кадастровым синим цветом `#2F5B8A`.
- Парящая карусель карточек участков с бейджами Trust Score и статусом ясности.

### 2. Цифровой паспорт риска (Ядро ANYQ)
- Вердикт ясности участка (Чист к застройке / Требуется проверка).
- Кадастровый номер с маскировкой (`20-315-•••-•••`).
- **Kaspi Pay симуляция**: покупка «Отчёта ясности» за 3 900 ₸ → моментальное раскрытие кадастрового номера и координат.
- Юридические зоны: Сейсмика 9–10 баллов Алматы, красные линии дорог, водоохранная полоса, охранная зона ЛЭП.
- Инженерные сети: статус подключения электричества, газа, воды, канализации и подъездной дороги.
- Заказ сертифицированных услуг: выезд геодезиста, разработка ПСД, авторский надзор.

### 3. Калькулятор сметы (BOQ)
- Динамический расчет стоимости строительства коттеджа под ключ.
- Параметры: площадь (80–450 м²), этажность (1–3 этажа), материал стен (газоблок, кирпич, монолит).
- Структура затрат: фундаментная плита, стены и перекрытия, кровля, инженерия, черновая отделка.
- Детализированная ведомость объемов работ (BOQ) с физическими объемами и единичными расценками в тенге.

### 4. Цифровая стройплощадка & BIM 3D
- **Интерактивный 3D просмотрщик BIM-модели коттеджа**:
  - Вращение модели на 360° жестами пальца.
  - Масштабирование (Pinch-to-zoom).
  - Слайдер вертикального среза / сечения по высоте (от 1.0м до 9.0м).
  - Переключатели слоев: *Архитектура*, *Железобетон*, *Кровля*, *Инженерия ОВ/ВК*, *Арматура*.
  - Инспекционные метки элементов конструкции.
- Интерактивный график Ганта с процентами готовности этапов.
- Электронные акты приемки КС-2 / КС-3 с модальным окном цифровой подписи (ЭЦП).

### 5. Личный кабинет и CRM
- Мгновенное переключение демо-ролей: **Покупатель**, **Продавец**, **Модератор**, **Админ**.
- Раздел «Избранные участки».
- CRM-воронка: активные сделки, статусы (эскроу, генподряд, поставка материалов), бюджеты.
- Очередь модерации для модераторов/админов с кнопками одобрения и возврата на доработку.
- Мгновенное переключение языка интерфейса: **Қазақша (KK)** / **Русский (RU)**.

## 🚀 Как запускать

Flutter SDK установлен в систему: `C:\Users\Амир\flutter\bin`.

### Быстрый запуск в браузере (Chrome):
```bash
cd superapp/apps/mobile
flutter run -d chrome
```
*Или из корня репозитория:*
```bash
npm run dev:mobile
```

### Запуск на подключенном Android устройстве или эмуляторе:
```bash
cd superapp/apps/mobile
flutter run
```

### Сборка релизного APK:
```bash
cd superapp/apps/mobile
flutter build apk --release
```
Файл APK будет сформирован в `build/app/outputs/flutter-apk/app-release.apk`.
