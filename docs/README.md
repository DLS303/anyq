# Документация

## Регистрация

`REGISTRATION_ENABLED` и `NEXT_PUBLIC_REGISTRATION_ENABLED` включают публичную регистрацию только при значении `1`.

Пустое значение, `0`, `true`, `yes` и любое другое значение оставляют регистрацию закрытой. `POST /v1/auth/register` отвечает `403` с текстом `Регистрация недоступна` до проверки тела. Сайт прячет `/register` и ссылки на регистрацию. Вход существующих аккаунтов, включая `@demo.superapp`, не меняется.
