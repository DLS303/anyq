# ANYQ / АНЫҚ — дизайн-система

Версия 0.1 · сентябрь 2026  
Продукт: витрина земли Алматы → паспорт риска → действие → Kaspi.  
Философия: **ясное стекло над землёй**.

---

## Key Decisions

1. **Primary = кадастровый синий `#2F5B8A`.** Это цвет геодезической линии и ясности, не стройки. Терракота `#B56A43` — тепло земли *под* стеклом (фон, зерно, спутник), не второй CTA. На одном экране один акцент.
2. **Light — дефолт MVP.** День, бумага, спутник. Dark — ночной бетон для кабинета и площадки позже.
3. **Стекло плавает над фактурой**, фон местами остаётся резким (карта/спутник). Не размывать весь viewport.
4. **MVP-экраны только:** витрина, паспорт риска, оплата отчёта, заказ услуги, empty, landing. Супер-приложение ролей в UI не раздуваем.
5. **Шрифт Inter + IBM Plex Mono.** Кириллица и қазақ әіңғұқөһ, моно для кадастра.

## 2. Типографика

- **UI:** Inter (400/500/600), `cyrillic` + `cyrillic-ext`.
- **Данные:** IBM Plex Mono 400/500 — кадастр, координаты, ₸.
- **Hero только:** тот же Inter, weight 500, большой tracking. Без декоративного серifa — меньше «журнал путешествий», больше финтех-ясность.

| Стиль | Size / lh / tracking | Применение |

## 3. Стекло — 3 уровня

### L1 · навбар / фильтры
- blur **20px**, fill **8%**, border 1px `rgba(255,255,255,0.15)`
- тень почти нет
- при скролле fill → 11%, blur 24px (контент под панелью читается чуть глуше)

### L2 · карточка участка / модуль услуги
- blur **36px**, fill **11%**
- inset highlight: `inset 0 1px 0 rgba(255,255,255,0.45)`
- внешняя тень: `0 18px 50px rgba(28,25,21,0.10)`
- hover: fill 14%, translateY(−2px)
- press: scale **0.98**, fill 16%
- spring: `transition: 420ms cubic-bezier(0.22, 1, 0.36, 1)`  
  Framer: `mass: 0.8, stiffness: 280, damping: 24`

### L3 · модалка (отчёт / Kaspi)
- blur **56px**, fill **16%**
- border 1px `rgba(255,255,255,0.42)`
- тень `0 28px 80px rgba(28,25,21,0.22)`
- specular: радиальный блик 180px в верхнем левом, opacity 0.18

Появление стекла: opacity 0→1 + blur 12→целевой, 360ms. Не scale-in с 0.8 — это Control Center.

## 4. Экраны

### 4.1 Витрина Алматы
**Твёрдое:** карта/спутник на 100vw×100vh, контуры участков тонкой кадастровой линией `#2F5B8A` 1px.  
**Стекло:** L1-фильтры сверху (район, сотки, ₸, ясность); L2-карточки справа (desktop) / снизу шитом (mobile).  
**Сетка:** mobile 1 col, карточки 16px gutter, карта под ними. Tablet split 40/60. Desktop карта full-bleed, rail 380px.  
**CTA primary:** открыть паспорт. Secondary: «только с паспортом».  
**Состояния:** loading — скелет стекла + зерно бумаги; empty — «В этом районе нет ясных участков» + зерно, без иллюстрации каски.

### 4.2 Паспорт риска
**Твёрдое:** спутник + полигон этого участка (60% ширины desktop / верх mobile).  
**Стекло L2:** вердикт, сети, ограничения, кадастр mono.  
**Индикатор ясности:** пилюля L1 — изумруд / янтарь / серый.  
**CTA primary:** «Отчёт ясности · 3 900 ₸». Secondary: «Выезд геодезиста».  
**Не маскировать кадастр после оплаты отчёта** — до оплаты маска `20-315-•••-•••`.

### 4.3 Оплата отчёта (Kaspi)
L3-модалка 400px, цена крупным mono, одно поле телефона если нет сессии, кнопка Kaspi.  
Успех: пилюля ясности серый→зелёный, без конфетти.

### 4.4 Заказ услуги
На той же карточке объекта, не отдельный маркетплейс. Три капсулы L2: геодезист / ПСД / архитектор. Иконка + цена + CTA. Привязка `plot_id` обязательна.

### 4.5 Empty / loading
Канвас `--bg-canvas` + noise 2.5% + едва видимая миллиметровка (opacity 0.04). Одна caption: «Собираем ясность». Не спиннер на весь экран.

### 4.6 Landing
Hero: спутник в полный экран, поверх — стеклянные узлы цепочки  
**Земля → ясность → действие → деньги → стройка**  
«Стройка» визуально приглушена (ещё не в релизе). H1: «Сначала ясность, потом лопата.»  
CTA: «Смотреть участки Алматы».

## Иконография

Stroke 1.5, round caps. Кастом: паспорт (лист+крест теодолита), красные линии (ломаная), сети (узел), геодезист (штатив), ПСД (пачка листов).  
Пилюли ясности: 8px точка + подпись Caption.
